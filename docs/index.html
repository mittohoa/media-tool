Máy tính

Tìm ảnh trùng trên tập dữ liệu lớn rải rác nhiều ổ đĩa — kể cả những bản đã bị xoá metadata, thứ mà mọi tool dựa trên hash file đều bỏ sót.

  • So pixel sau khi giải mã, không so byte file
  • Chuyển file vào khu cách ly chứ không xoá; hoàn tác được 14 ngày
  • Cứu EXIF từ bản sắp loại sang bản giữ, không đổi một pixel nào

Winnow làm gì mà tool khác không làm

Xoá EXIF không đụng một pixel nào, nhưng làm đổi hoàn toàn hash của file. Với tool so byte, hai bản của cùng một tấm ảnh trở thành hai tấm khác nhau.

1️⃣

Trùng byte

Cùng dung lượng và cùng xxHash128 của file. Bản copy y hệt, không sai sót.

2️⃣

Trùng pixel

Giải mã ảnh rồi hash buffer pixel. Đây là tầng bắt được bản mất metadata mà tầng 1 bỏ sót.

3️⃣

Gần trùng

Hash tri giác cộng bản đồ khác biệt, cộng giờ chụp EXIF để không nhầm hai tấm chụp cách nhau một giây với một tấm lưu hai lần.
